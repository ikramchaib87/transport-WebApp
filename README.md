# 🚍 Transport WebApp  
Personnel Transportation Management System  
(L3 Final Year Project)

## 📖 Overview
Transport WebApp is a full-stack web application developed as part of my L3 final year project in Computer Science.

The system was designed and implemented for the Transport Service at Sonatrach (Centre d’Innovation) to manage and organize personnel transportation operations efficiently.

---

## 🎯 Objectives
- Centralize personnel transport management
- Organize vehicle and route assignments
- Manage internal and external chauffeurs
- Improve administrative efficiency and tracking

---

## 🧩 System Architecture
This is a full-stack application built with:

- **Backend:** Node.js  
- **Database:** PostgreSQL  
- **Directory Service & Authentication:** LDAP (Linux environment)  
- **Frontend:** HTML, CSS, JavaScript  

---

## 🔐 Authentication & User Management
The application integrates LDAP-based authentication.

- Employee and Admin accounts are verified using LDAP
- New employees are validated through LDAP and Gmail verification
- Secure login system implemented for Admin and Employee roles

---

## 👥 User Roles
The system supports multiple user roles:

- **Admin**
  - Manage employees
  - Assign vehicles and routes
  - Oversee transport operations

- **Employee**
  - Access personal transport information

- **Chauffeur (Internal & External)**
  - Manage assigned routes
  - View transport schedules

---

## 🗄 Database Design
PostgreSQL is used to manage:

- Employee records
- Chauffeur data (internal & external)
- Vehicle information
- Route assignments
- Transport schedules
